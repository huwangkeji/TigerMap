## 项目简介

**虎王星图网络拓扑图** 是一个零依赖、纯前端的网络拓扑可视化工具，专为网络工程师、运维人员、教师与学习者设计。

- 不需要后端服务器，不需要数据库，不需要联网
- 所有数据保存在浏览器本地，隐私安全
- 资源完全本地化，无外部 CDN 调用
- 解压即用，适合内网 / 离线环境部署

适合场景：机房拓扑绘制、网络架构图、教学演示、方案汇报、故障定位示意。

## 功能特性

### 绘图与编辑
- **拖拽式绘图**：从左侧设备库拖入图标到画布，双击可快速放到画布中心
- **智能连线**：悬停设备拖出边缘蓝色圆点到目标设备；或按 `L` 进入连线模式后依次点击两台设备
- **丰富设备库**：路由器、交换机、防火墙、服务器、无线 AP、光猫、NAS、UPS、云、负载均衡等 19+ 内置设备类型
- **自定义设备**：支持三种图标来源 —— 内置图标库 / 表情文字 / 上传自己的 SVG，建好后与内置设备一样可拖拽连线
- **单设备换肤**：选中设备可单独改图标、显示尺寸（小/标准/大）、强调色、是否隐藏 IP，不影响同类型其他设备
- **框选 / 多选**：空白处拖动框选；`Shift`+点击 增减选中；`Ctrl+A` 全选
- **复制 / 再制**：`Ctrl+C` / `Ctrl+V` / `Ctrl+D`，方向键可微调位置
- **撤销 / 重做**：完整操作历史，`Ctrl+Z` / `Ctrl+Shift+Z`

### 视图与布局
- **自动布局**：以选中设备（或第一台）为根，按连接层级自动排列，支持横/纵布局切换
- **缩放与平移**：滚轮缩放；空格/中键/右键拖动平移；`Ctrl+0` 一键适应画布
- **深色主题**：一键切换亮/暗模式，长时间看图更护眼
- **状态图例**：在线(绿) / 告警(橙) / 离线(红) / 未知(灰) 一目了然

### 实时监控
- 开启「实时监控」后可模拟设备状态变化与链路流量动画
- 支持手动指定每台设备的在线/告警/离线/未知状态
- 链路带流动光效，直观呈现数据走向

### 导出与分享
- **PNG**：2 倍高清位图，适合插入文档/PPT
- **SVG**：矢量图，无损缩放，适合二次编辑
- **PDF**：可选贴合内容尺寸或 A4 纸张（自动横竖，居中缩放），图像无损嵌入
- **JSON 工程**：保存后可再次导入继续编辑，支持版本迭代

### 工程持久化
- 工程自动保存至浏览器 `localStorage`，刷新不丢
- 也可手动「保存」导出 JSON 文件本地归档

## 快速开始

### 方式一：直接打开（推荐）

下载本项目，浏览器直接打开 `index.php` 即可使用。

> 无需安装任何运行环境，无需联网。

### 方式二：PHP 内置服务器

```bash
# 进入项目目录后执行
php -S localhost:8000
```

然后访问 `http://localhost:8000`

### 方式三：PHPStudy / Nginx / Apache

将项目目录配置为站点根目录即可。Nginx 伪静态参考见 `nginx.htaccess`。

## 操作说明

| 操作 | 方法 |
|------|------|
| 添加设备 | 从左侧设备库**拖拽**到画布，或**双击**图标放到中心 |
| 连接设备 | 悬停设备 → 拖出蓝色圆点到目标；或按 `L` 后依次点击两台设备 |
| 框选 / 多选 | 空白处左键拖动框选；`Shift`+点击 增减；`Ctrl+A` 全选 |
| 平移 / 缩放 | 滚轮缩放；空格/中键拖动平移；`Ctrl+0` 适应画布 |
| 复制 / 粘贴 | `Ctrl+C` / `Ctrl+V` / `Ctrl+D` 再制；方向键微调位置 |
| 删除 | 选中后按 `Delete`，或右键 → 删除 |
| 重命名 / 改 IP | 选中后在右侧属性面板编辑，画布标签实时更新 |
| 实时监控 | 开启后模拟设备状态与链路流量动画，可手动指定状态 |
| 导出 | PNG（2 倍高清）/ SVG 矢量图 / PDF 文档 / 工程 JSON |
| 自动布局 | 选中设备后点「自动布局」，按层级排列（横/纵切换） |
| 自定义设备 | 点顶部「自定义设备」或设备库底部「＋ 新建」 |
